## Core Architecture

### P2P Communication

- **[P2P Free Instructions](./p2p_free_instructions.md)** - Direct peer-to-peer communication channel for freeing KV cache blocks after sequence migration. Foundation for automatic resource management in disaggregated deployments.

- **[MR Info Architecture](./mr_info_architecture.md)** - Multi-rail network architecture information.

## Performance Optimizations

### Prefill-Decode Disaggregation

- **[Early Free Migration](./early-free-migration.md)** - Optimization that releases prefill engine KV cache blocks immediately after migration completes (rather than waiting for full generation). Saves ~500ms per sequence and significantly improves prefill throughput.
